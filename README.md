# The Paper Crane Academy

An educational platform for students exploring law, politics, international relations, public policy and economics: courses with quizzes and certificates, a student press with editorial review, an opportunities directory, activities, portfolios and an AI study assistant.

**Live app:** https://claude.ai/artifact/QRkiFMJesjjXc2bQ3ZgLFk

## Files

- `index.html` – the whole app (HTML, CSS and JavaScript in one file)
- `crane-medallion.png`, `crane-cutout.png` – emblem artwork

## Note

The sign-in, saved progress, shared database, AI assistant and PDF downloads run on Claude's artifact platform. If you open `index.html` directly or through GitHub Pages, the design and pages load, but those features stay switched off and the course and article lists are empty.
